// 必殺技
フラフラニール

黄金町をフラフラ散歩する必殺技。

歩けば歩くほど、パートナーザジモンのやる気とパワーがアップする。

// 上演ゲージ シミュレーション
歩行距離: 1.2km / 1.5km
⚡ もうすぐ　上演イベントが　はじまる！
// 対応ザジモン
🦎 ザジカゲ 高架下・路地裏
🐢 ジズガメ 川沿い・水辺
🌱 ザジズダネ 公園・草むら
// 開発メモ（追記）
当初は経験値システムを実装する予定だったが、「歩くこと自体をご褒美にしたい」という理由から、経験値の代わりに上演ゲージを採用。

街を歩くほど、街そのものが劇場になっていく。

キャラクターデザインは木皮さんが担当予定。どんなザジモンが生まれるのか、とても楽しみ。
