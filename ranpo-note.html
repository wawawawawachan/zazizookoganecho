「ザジボールについて」
ZAZIMON PROJECT — CONFIDENTIAL
▶ DEVICE IMAGE: ザジボール
▶ CHARACTER PROFILE: ランポくん
// 01 — 個体識別

正式名称：RANPO Navigation Player (RNP-01)

コガネタウンに潜む「街の記憶」を採集・観測するための器。プレイヤーは本機を介して街を回遊するが、システム上、これは「探索」ではなく「散歩」として処理される。

移動距離と滞在時間に比例し、住民や建造物から抽出された記憶が蓄積。それに応じ、マップデータはリアルタイムで再構成される。

// 02 — 仕様変更の経緯

当初の設計案にあった「謎解き・事件解決」の要素は全廃した。

「事件を解決する」のではなく、「事件を内包したまま継続する街を見続ける」という観測者としての仕様へ変更。

攻撃コマンドは一切実装されていない。許可された行動は、ただ以下の4つのみである。

・見る
・歩く
・覗く
・振り返る

// 03 — 街との同期

ランポくんの「視点」は街のデータと共有される。プレイヤーが景色を観測した瞬間、街の記憶に書き込まれる。

相互の同期が進むにつれ、「プレイヤーが街を歩いている」のか、「街がプレイヤーを歩かせている」のか、その主客は曖昧となる。

※ 開発者コメント（アーカイブより） 「ランポくんは主人公ではない。プレイヤーが街の『眼』になるための器だ。
コガネタウンは、誰かに歩いてもらうことで初めてその存在を証明できる。」
