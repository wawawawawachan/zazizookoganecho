// 01 — ザジボールとは

ザジボールは、ザジモンを捕まえるための道具。ただ投げるだけのボールではない。

ザジボールは、相手との「出会い」を記録する装置だ。相手の名前を知り、言葉を交わし、その存在を認識したとき、初めてボールは反応する。

// 02 — 効かない条件

だから、逃げている相手には効かない。見つけようとしていない相手にも効かない。

ザジボールは、「会えた」という事実そのものを保存する。

// 03 — ゲームと現実

ゲームではボタン一つで捕獲できるように見えるけれど、本当はそうじゃない。

人は、人に会わないと捕まらない。だからザジモンGOでは、実際に街へ出て、人に会ってもらう仕様にした。少し不便だけど、そのほうが本物だから。

もしかしたら、「話しかけること」自体がザジボールなのかもしれない。
